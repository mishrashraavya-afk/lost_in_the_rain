# Lost in the Rain

Cozy rainy narrative exploration game. Phaser 3 + Vite (Capacitor for Android later).

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

Controls: WASD / arrows to walk, E / Space to look closer, M to mute. Touch: hold to walk, tap the marker.
Debug: add `?canvas` to the URL to force the Canvas renderer.

All art and audio are generated in code (src/art, src/systems/AmbientAudio.js), so there are no external assets or licences.
